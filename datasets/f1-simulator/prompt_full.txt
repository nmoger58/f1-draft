## 2. Two multiplayer room types

### A. Custom Room

A Custom Room is created by a host who wants to race with invited friends.

Required behavior:

- Provide a **Create Custom Room** option on the multiplayer landing page.
- Let the host configure the existing supported race settings, including circuit, race distance, qualifying, and other available options.
- Generate a unique room ID and provide a copyable room invitation code.
- Allow players to join using the room ID or an invitation link.
- Keep the room private by default. It must not appear in the public room browser.
- Show the host and all joined participants in a live waiting room.
- Allow the host to control the start of the game, subject to existing server-side readiness and validation rules.
- Display the host's room name, selected circuit, player count, race format, and waiting status in the host's room interface.
- Preserve the existing host permissions and shared multiplayer configuration.
- Provide clear states for waiting, preparing, racing, completed, and closed rooms.

Custom room privacy must be enforced on the server, not just hidden in the frontend.

### B. Public Room

A Public Room is discoverable by other players without requiring them to know or enter a room ID.

Required behavior:

- Provide a **Create Public Room** option.
- Let the host configure the supported race settings before creating the room.
- Publish eligible public rooms to a live room browser on the multiplayer landing page.
- Allow any eligible player to click **Join Race** and enter the room directly without manually entering a room ID.
- After joining, collect or confirm the player's room-specific display name if it has not already been supplied.

- Allow the host to choose whether the room starts manually or automatically when a configured player threshold is reached, if compatible with the existing start system. Manual start should remain the default.
- Provide a **Leave Room** action that returns the player to the multiplayer landing page without accidentally deleting the room or disrupting other players.

Public visibility does not mean that every room is joinable at every stage. Only rooms in an eligible waiting state should offer direct joining.
